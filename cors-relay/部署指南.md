# 知乎小说工作台 · 跨域转发部署指南（国内可用版）

> 用途：解决手机/浏览器直连日日新 API 时，因 `OPTIONS` 预检返回 404 被跨域拦截的问题。
> 部署后，App 内就能直接调用 AI（模式 B），自动填提示词、流式回显、存稿，不用手抄。

---

## ⚠️ 重要前提（踩过的坑）

**Cloudflare Workers 的 `*.workers.dev` 域名在中国大陆网络下经常被墙/干扰，无法直接访问。**
所以如果你在中国大陆，请**直接用下面的「腾讯云函数」方案**，不要走 Cloudflare（除非你有自己的域名可绑到 Worker 上）。

---

## 方案一（推荐，国内稳定）：腾讯云函数 SCF

域名 `*.apigw.tencentcs.com` 国内直连可用，免费额度个人够用，需微信/QQ 实名（中国用户基本都有）。

### 准备
- 腾讯云账号（已实名）
- 你的日日新 Key（`sk-...`）

### 步骤（约 5 分钟）
1. 打开 https://console.cloud.tencent.com/scf → **新建函数 → 自定义创建**
2. 运行环境选 **Python 3.10**，函数类型选 **Web 函数**（不是事件函数）
3. 把同目录 **`scf_relay.py`** 内容粘贴到入口文件
4. 函数配置 → **环境变量** 添加：
   | 变量 | 值 |
   |------|----|
   | `RELAY_SECRET` | 随意一长串，如 `a1b2c3d4` |
   | `SEN_NOVA_KEY` | 你的 `sk-...`（可选；填了 App 端 Key 可留空，最安全） |
   | `STRIP_PREFIX` | 留空即可（脚本会自动剥 `/release`、`/prod` 前缀） |
5. **触发器管理 → 访问路径**，得到公网 URL，形如：
   `https://xxx.apigw.tencentcs.com/release/`
6. 小说 App → **设置 → AI 接口**，填写：
   - **Base URL**：上面那个 URL（保留结尾 `/`，**不要**写 `/v1`，网关已含路径）
   - **API Key**：若设了 `SEN_NOVA_KEY` 则留空，否则填 `sk-...`
   - **转发共享密钥**：填同一个 `RELAY_SECRET`
   - 模型 ID：`sensenova-6.8-flash-lite`
7. 点 **「保存配置」→「测试连接」**，出现 `✅ 连接成功` 即完成

## 方案二（零门槛，仅同 WiFi）：本地 Node 转发

适合先在电脑上验证 App 流程，**手机必须与电脑连同一个 WiFi**，电脑关机即失效。

1. 电脑打开 cmd，进入 `cors-relay` 目录
2. 运行：
   ```
   set RELAY_SECRET=a1b2c3d4
   set SEN_NOVA_KEY=sk-你的日日新key
   node local_relay.js
   ```
3. cmd 输入 `ipconfig` 查「IPv4 地址」（如 `192.168.1.20`）
4. App Base URL 填 `http://192.168.1.20:8787/v1`，Relay Secret 填 `a1b2c3d4`
5. 点测试连接

> 长期稳定请部署方案一（腾讯云函数）。

---

## 方案三（有域名才用）：Cloudflare Workers + 自定义域名

仅当你**有自己的域名**时推荐（自定义域名不被墙）：
1. 按原 `worker.js` 部署 Cloudflare Worker
2. Worker 页面 → **自定义域 / Custom Domains** → 绑定 `relay.你的域名.com`
3. App Base URL 填 `https://relay.你的域名.com/v1`
（若只用 `*.workers.dev` 默认域名，国内大概率连不上，勿用）

## 安全说明

| 模式 | App 填什么 | 密钥在哪 | 安全等级 |
|------|-----------|---------|---------|
| 透传（默认） | API Key + 可选 Relay Secret | 浏览器 localStorage | 中 |
| **密钥托管（推荐）** | 仅 Relay Secret，Key 留空 | 只在服务端环境变量 | **高**（Key 永不进浏览器） |

`RELAY_SECRET` 防止公网 URL 被当开放代理刷额度（无密钥直接 403）。
**切勿使用任何「公共 CORS 代理」**，那会让密钥经过第三方。

---

## 排错

| 现象 | 原因 / 解决 |
|------|------------|
| `403 forbidden` | `RELAY_SECRET` 与 App 填的「转发共享密钥」不一致 |
| `401` | Key 无效/过期（透传）；或密钥托管模式 `SEN_NOVA_KEY` 填错 |
| 仍 `CORS/网络失败` | SCF 方案确认 Base URL 没多写 `/v1`；腾讯云函数需「保存」后等 10 秒生效 |
| `502` | 服务端到日日新网络抖动，稍后重试 |
| 连不上 `workers.dev` | 国内被墙，换方案一/三 |
